# TaxGuard AI - Income Tax Fraud Detection System

## Overview

TaxGuard AI is an AI/ML-based fraud detection system developed to identify suspicious income tax filings using machine learning techniques.

## Features

- Secure Login System
- Single Taxpayer Fraud Prediction
- Batch CSV Fraud Detection
- Analytics Dashboard
- Fraud Probability Estimation
- PDF Report Generation
- Cyber-Themed User Interface

## Machine Learning Models

- Random Forest
- XGBoost
- Logistic Regression

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- Pandas
- Plotly

## Dataset

The system uses taxpayer attributes such as:

- Annual Income
- Declared Tax
- GST Mismatch
- Shell Company Linkage
- Cash Deposit Spike
- High Risk Industry
- Deduction Risk
- Expense Anomaly

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
